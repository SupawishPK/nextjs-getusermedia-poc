📷 POC: getUserMedia (สิทธิ์กล้อง/ไมค์)

ทดสอบการขอ permission กล้อง/ไมค์ทุกรูปแบบในหน้าเดียว — ทุก event ถูก log ไปที่ console, หน้าจอ และ localStorage (ดาวน์โหลดเป็นไฟล์ได้)

Next.js 7 รูปแบบการขอ + enumerateDevices + Permissions API + getDisplayMedia

1) สถานะสิทธิ์ปัจจุบัน (Permissions API)

กล้อง: unknownไมค์: unknownstream: idle

💡 granted = อนุญาตแล้ว | prompt = ยังไม่เคยถาม (เบราว์เซอร์จะ popup เมื่อกดปุ่มขอสิทธิ์) | denied = ถูกปฏิเสธ ต้องไปรีเซ็ตที่ตั้งค่าเบราว์เซอร์/OS

2) ขอสิทธิ์ (getUserMedia) — ทุกแบบ

3) อุปกรณ์ที่ตรวจพบ (enumerateDevices)

🖱️ คลิกที่ deviceId เพื่อคัดลอก · สแกนอัตโนมัติเมื่อเสียบ/ถอดอุปกรณ์ (devicechange) · label จะโผล่หลังขอสิทธิ์แล้ว

ยังไม่มีข้อมูล — กดปุ่ม "สแกนอุปกรณ์" หรือขอสิทธิ์กล้องก่อน แล้ว label ของอุปกรณ์จะโผล่

4) พรีวิว + ข้อมูล stream

รอสตรีมจากกล้อง...

5) Log (console + localStorage + ดาวน์โหลด)
